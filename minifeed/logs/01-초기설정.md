# #1 초기 설정

## Android 플랫폼만 생성

- AI 제안: `flutter create --platforms android`로 Android 폴더만 만든다.
- 판단: 채택
- 이유: 과제 범위가 Android 실기기(R7)다. Firebase를 붙일 때(MP2) `flutterfire configure`가 플랫폼마다 설정을 만들고, Windows 데스크톱은 Firebase 지원이 제한적이다. 웹이 필요하면 `flutter create --platforms web .`로 나중에 추가한다.

## Kotlin 증분 컴파일 끄기

- AI 제안: `android/gradle.properties`에 `kotlin.incremental=false`
- 판단: 채택
- 이유: 프로젝트(E:)와 Pub 캐시(C:)가 다른 드라이브면 Kotlin 증분 컴파일러가 상대 경로를 못 구해 빌드가 깨진다("different roots"). toonflix에서 겪은 문제를 미리 막는다.

## 끝 쉼표 포맷 유지

- AI 제안: `analysis_options.yaml`에 `formatter: trailing_commas: preserve`
- 판단: 채택
- 이유: Dart 3.7부터 포매터가 끝 쉼표를 무시하고 줄 길이로만 줄바꿈한다. 끝 쉼표를 찍으면 인자가 한 줄에 하나씩 펴지는 예전 동작을 쓰려면 이 옵션이 필요하다. `dart format`으로 끝 쉼표가 있을 때만 펴지는 것을 확인했다.
